## Found and fixed during this round

1. **Cluster bus race.** Publish numbers an event before writing it, and a poller in between
   skipped the event. Two of four pods missed a manually published event. Fixed, with a spec
   that reproduces the race.
2. **Partial logs never read.** Rundeck asks `isPartialAvailable()` before tailing another pod's
   execution, and the plugin returned the default `false`. Implemented.
3. **Cookie settings not applied.** Spring Session's optional autowired cookie-serializer setter
   isn't applied to Grails BeanBuilder beans, so the cookie name and Secure flag were ignored.
   Wired explicitly.
4. **Test harness: graceful shutdown.** A graceful scale-down lets Rundeck abort its own
   executions, so the sweeper is now tested with a forced kill.
5. **Test harness: clock skew.** This machine's clock ran 15 s ahead of AWS, so checks now read
   logs in relative time windows.
6. **Test harness: masked deploy failure.** A transient EKS API timeout failed one deploy, and a
   `| tail` hid it, so checks briefly ran against the previous build. Deploys are now checked
   with `pipefail`.
